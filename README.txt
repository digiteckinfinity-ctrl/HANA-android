HANA Android V1
================
Native Android project. Ask AI / Netlify / API are intentionally removed.

Included:
- Android microphone permission (RECORD_AUDIO)
- Record -> Android Korean speech recognition -> transcript preview -> Send
- Korean sentence + easy pronunciation + English + Tamil
- Vocabulary breakdown
- Korean Text-to-Speech replay
- Built-in offline lesson/conversation flow
- Ready structure for expanding Levels 1-6, MCQ, progress and more lesson data

Important:
Speech recognition availability/offline behavior depends on the Android device and installed speech service/language pack.
Korean TTS also depends on an installed Korean voice.
This ZIP is Android source code, NOT a compiled APK.

Build:
Open the project in Android Studio (or a compatible Android Gradle build environment), let Gradle sync, then Build > Build APK(s).
